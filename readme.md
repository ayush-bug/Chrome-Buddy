# Chrome buddy 
It is a chrome extension that help you to trace your daily usage ,

remind you to stay hydrated .

also show your yesterday usage and last 7 days usage .

you can also create your personal reminder and recieve chrome notifications.

# features

IT will trace all the website you visit , time you spent on that site .

It has a dashboard that help to see all your usage of today , yesterday and last 7 days.

Personal reminders : you can create your own personal reminders form the dashboard. that help you to be on time. 

the reminders will be shown through chrome notifications.

It also has default water intake reminder to keep you hydrated . (I include this feature becaue of my personal reason , I drink very less water , soo thats way i add this too.)

 Then go to <pre> chrome://extensions</pre>

Enable the developer mode

click on the load unpack the selct the downloaded file.
after that we can you it on your browser.
